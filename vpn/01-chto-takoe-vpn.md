## Кто видит ваш трафик без VPN

Пакет идёт цепочкой: ваше устройство → роутер → провайдер (ISP — Internet Service Provider, поставщик интернет-услуг) → транзитные сети → сервер сайта.

- **Провайдер видит**: ваш реальный IP-адрес (IP — Internet Protocol, интернет-протокол — «язык адресов» в сети), домены, время и объём трафика. Домены утекают через DNS-запросы (DNS — Domain Name System, система доменных имён — «телефонная книга» интернета) и поле SNI (Server Name Indication — «указание имени сервера») внутри рукопожатия TLS (Transport Layer Security — протокол шифрования соединения). Содержимое запросов — только если сайт работает без HTTPS (HyperText Transfer Protocol Secure — защищённый протокол передачи гипертекста; HTTP — HyperText Transfer Protocol).
- **Сайт видит**: ваш реальный IP-адрес, User-Agent, куки, данные запросов.

## Что меняется с VPN

- Провайдер видит **только зашифрованное соединение с сервером VPN** (Virtual Private Network — виртуальная частная сеть): ни доменов, ни содержимого.
- Сайт видит **IP-адрес VPN-сервера** вместо вашего — запрос уходит с сервера уже от его имени.
- Появляется новая доверенная сторона: **VPN-сервер видит всё** (ваш IP + весь трафик после распаковки туннеля).

## Определение и три свойства

**VPN (Virtual Private Network** — виртуальная частная сеть) — способ провести трафик через недоверенную сеть так, будто есть прямой приватный канал до своего сервера.

1. **Туннель (tunnel)** — весь трафик перехватывается на устройстве и направляется в точку выхода.
2. **Шифрование (encryption)** — содержимое туннеля недоступно посредникам.
3. **Своя точка выхода (exit node)** — запросы уходят с VPN-сервера, подменяя IP источника.

Механика — **инкапсуляция (encapsulation)**: ваш пакет упаковывается в зашифрованную внешнюю оболочку, адресованную VPN-серверу; сервер распаковывает её и отправляет внутренний пакет дальше от своего имени. Детали — в модулях [[03-tunnel-i-perehvat-trafika]] и [[04-pochemu-menyaetsya-ip]].

## Четыре сценария применения

1. **Приватность в чужих сетях** — публичный Wi-Fi: локальная сеть видит только шифротекст.
2. **Обход блокировок и гео-ограничений** — провайдеру нечего блокировать (виден только VPN-сервер), сайты видят страну сервера.
3. **Удалённый доступ к корпоративной сети** — классический сценарий: доступ к внутренним сервисам через VPN-шлюз офиса.
4. **Site-to-site и mesh** — туннель между дата-центрами/офисами или между всеми вашими устройствами (Tailscale, WireGuard).

## Чего VPN не делает

- **Не даёт анонимность**: VPN-провайдер видит весь трафик (подробнее — [[09-utechki-i-ogranicheniya]]).
- **Не защищает от фишинга, трекеров в страницах, слабых паролей** — только канал передачи.
- **Не ускоряет интернет** — обычно замедляет (крюк до сервера + шифрование).
